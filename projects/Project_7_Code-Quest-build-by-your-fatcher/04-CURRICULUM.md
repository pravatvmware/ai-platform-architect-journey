# 04 · Curriculum

Every Learning Path lesson is available in **Python, C#, C++ and Java**, and ends with an assignment themed to the learner's interest (Games, 3D Animation, VFX or Film).

## Learning Path: 165 lessons

## Design principles

1. **Small steps.** Each small lesson teaches one idea, in about 5–15 minutes.
2. **Same idea, four languages.** Comparing languages builds real understanding.
3. **Relevance first.** Assignments are rewritten for his interest; Tool Track connects to the software he uses.
4. **Plain language.** Syntax notes quote his own code and explain in one simple sentence.
5. **Gradual unlock.** Lessons unlock in order, but he can open everything if he wants to explore.
