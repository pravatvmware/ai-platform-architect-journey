# 02 · What we built

## Summary

A self-contained learning platform: a small Python web server plus a single-page front end, packaged in Docker. It teaches four languages through four interests, links to professional 3D and game tools, and gamifies progress.

## Features

### 1. Interest and language choice
Four interests (🎮 Games, 🎬 3D Animation, ✨ VFX, 🎞️ Film) and four languages (🐍 Python, 🎯 C#, ⚙️ C++, ☕ Java). Every Learning Path lesson exists in all four languages, and the **assignment at the end is rewritten for the chosen interest**.

### 2. Runnable code in the browser
Each lesson has an editable code box with **Run** and **Reset**. Code is sent to the local server, which runs it with the real interpreter or compiler and shows the output or the error. Missing languages show as read-only instead of failing.

### 3. Learning Path: 165 lessons

| Level | Lessons | Topics |
|---|---|---|
| Beginner | 100 | Output, Variables and Comments, Data Types, Math Operators, Strings, Converting Types, If and Else, And/Or/Not, While Loops, For Loops |
| Intermediate | 40 | Lists and Arrays, Looping Through a List, Functions, Default Values, Dictionaries and Maps, Nested Loops, Splitting Text, Handling Errors |
| Expert | 25 | Classes and Objects, Inheritance, Filter and Sort, Recursion, Maths for Motion, Stacks and Undo, Boss Fight project |

Each topic has a main lesson followed by small lessons. Lessons unlock in order (or he can tick "Unlock all levels").

### 4. Plain-words syntax notes
Every lesson has a "🧠 Syntax in plain words" panel: two or three short notes that quote the lesson's own code piece by piece ("`range(5)` gives 0, 1, 2, 3, 4"). They are **generated by rules** from the code (see [Architecture](03-ARCHITECTURE.md#syntax-notes-generator)), so they stay correct when a lesson changes.

### 5. Pip, the mascot
An original SVG character at the bottom-right. Pip waves on a new lesson, "thinks" while code runs, cheers on success, tilts its head on an error with a hint, and celebrates finished lessons and level-ups. Tap Pip for a tip. Reduced-motion settings are respected. The SVG is a single block that can be replaced with the learner's own artwork.

### 6. XP, levels and a forgiving streak
+20 XP per lesson, +60 per Mini Project, a level every 100 XP. The streak forgives one skipped day. Progress is saved in the browser.

### 7. Real-world stories
A home-screen card shows a fresh headline from public RSS feeds for the chosen interest (Game Developer, Cartoon Brew, Blender, fxguide, No Film School, and others), with a "Coder angle" line and a link to the publisher. Headlines are filtered for age-suitability, cached for an hour, and replaced by built-in evergreen stories when offline.

### 8. Story Projects
Twelve themed mini lessons (three per interest) with real-world stories, in all four languages.

### 9. Tool Track: 28 lessons
Practice the idea in Code Quest, then **copy a ready script into real software**:

| App | Lessons | Language of the script |
|---|---|---|
| Blender | 8 | Python (`bpy`) |
| Maya | 4 | Python (`maya.cmds`) |
| Houdini | 4 | VEX and Python (`hou`) |
| Unity | 6 | C# |
| Unreal Engine | 6 | C++ |

Each lesson lists where to click, shows the script with a **Copy** button, and has a runnable practice version inside Code Quest (in Python, C# or C++).

### 10. Mini Projects: 4 builds
Step-by-step projects that combine lessons into something he can show friends. Each step has code to copy, a "You should see" check, and a tick box.

| Project | App | Outcome |
|---|---|---|
| The Bouncing Ball | Blender | A rendered 2-second MP4 |
| Coin Collector | Unity | A playable game with a score and a win |
| Raindrop on a Pond | Houdini | An animated ripple effect |
| Floating Pickups | Unreal (C++) | Spinning, floating pickups with a spawner and a counter |

### 11. Personal welcome
A greeting that changes with the time of day, ending with "Built with love by your Father, just for you."

### 12. Packaging and safety
Docker image with all four runtimes, Windows `Start`/`Stop` scripts, offline shipping instructions, and limits for memory, CPU, processes and capabilities.

## What was achieved

- ✅ A working, interest-driven platform the learner can use today
- ✅ Real output verified: the Python, C++ and Java versions of all 140 small lessons (90 Beginner + 50 Intermediate and Expert) give **identical results**
- ✅ A curriculum that grows from "print hello" to classes, recursion and a game feature in Unreal
- ✅ A bridge from coding to the tools of his craft
- ✅ A packaging and shipping path to his Windows laptop
- ✅ A codebase the builder can read, change and extend without web-development experience
